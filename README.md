## Parte 6 – Preguntas

**1. ¿Para qué sirve el archivo .gitignore?**
El archivo `.gitignore` sirve para indicarle a Git qué archivos o carpetas no debe rastrear ni incluir en el repositorio. 
Esto permite evitar subir archivos innecesarios o temporales.

**2. ¿Qué tipo de archivos es conveniente ignorar?**
Es conveniente ignorar archivos temporales, archivos de logs (como `.log`), archivos generados automáticamente,
archivos de configuración local y carpetas pesadas o innecesarias (por ejemplo, `node_modules`).

**3. ¿Un archivo ignorado se sube a GitHub?**
No, un archivo ignorado no se sube a GitHub, siempre y cuando no haya sido agregado previamente al repositorio.
